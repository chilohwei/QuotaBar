# 额度数据

## 数据模型

- `QuotaWindow`：用量窗口，包含已用值、上限和可选的重置时间。
- `QuotaDisplayMetric`：额度窗口与点数余额的展示类型。
- `QuotaSnapshot`：按账号存储的数据快照、订阅信息和采集时间。
- `QuotaSpend`：货币消费及可选上限，与请求额度、点数余额分开表示。
- `QuotaResetCredits`：可用重置次数、各次权益到期时间和独立查询时间。

## 服务映射

| 服务 | 主额度 | 详情 |
| --- | --- | --- |
| Codex | 5 小时、周额度 | 模型专属额度、代码审查、点数、可用重置次数与到期时间 |
| Claude Code | 5 小时、周额度 | 模型周额度、Routines、额外消费及消费上限 |
| Cursor | 总量、Auto、API | 按量额度、套餐内及按量消费、账单周期 |

百分比字段按百分比点处理。接口提供的货币小单位换算后显示币种；未知金额、上限、时间保留未知状态。模型专属窗口与按量消费不单独决定整个账号的可用性。

## 查询和时效

各服务通过 Provider 查询与账号匹配的数据，快照按账号隔离缓存。重置倒计时在本地更新，周期结束后需要服务端数据确认可用额度。缓存展示保留采集时间；补充字段失败不会被显示为零。

Codex 重置权益使用只读查询，与额度请求并行，独立限时 4 秒。应用不兑换重置权益。Claude 同时支持 OAuth 用量和 statusLine 信号；Cursor 使用账号对应的当前周期与汇总用量信息。

接口解析、账号隔离、缓存和刷新策略均有自动化测试。界面渲染使用模拟数据；模拟测试不替代真实账号与官方页面的数据核对。
