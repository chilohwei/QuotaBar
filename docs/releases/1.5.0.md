# QuotaBar 1.5.0

## 新增

- 在菜单栏查看 DeepSeek API 余额。账号卡片提供余额明细、多账号切换和 API Key 管理。
- 当 Codex 或 Claude Code 的本机配置指向 DeepSeek 官方后端时，可从顶部入口跳转到匹配的 DeepSeek 余额卡片，或确认导入 API Key。
- 当前账号额度耗尽且存在近期确认可用的备用账号时，可从卡片一键切换。

## 改进

- 后台每 30 秒检查当前 DeepSeek 账号。刷新失败时保留上次成功读数，悬停可查看更新时间和失败原因。
- 统一菜单栏图标的可见尺寸。
- 输入框支持 ⌘C、⌘V 和 ⌘A。切换应用后，弹窗保留未提交的内容。

## 安装

下载适合设备的 DMG：arm64（Apple Silicon）、x86_64（Intel）或 universal（通用），将 QuotaBar.app 拖入 Applications。安装包采用 Developer ID 签名并通过 Apple 公证，随附 SHA-256 校验文件。系统要求 macOS Ventura 13 或更高版本。
