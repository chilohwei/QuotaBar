# QuotaBar 1.0.0

QuotaBar 是 macOS 菜单栏额度管理工具，支持 Codex、Claude Code 和 Cursor。

- 多账号管理、本地账号切换与菜单栏额度显示。
- Codex / Claude 的 5 小时和周额度，独立重置倒计时、准确时间与时区。
- Codex 可用重置次数及权益到期详情。
- 模型专属额度、Claude Routines、点数与货币消费详情。
- Cursor 总量、Auto、API 额度和按量消费。
- 浅色与深色外观，中文、繁体中文及英文界面。

下载适合设备的 DMG：arm64（Apple Silicon）、x86_64（Intel）或 universal（通用）。将 QuotaBar.app 拖入 Applications，校验文件随安装包提供。

未配置 Developer ID 时，安装包使用 ad-hoc 签名、未经 Apple 公证。安装与首次打开说明见 README。
