# QuotaBar 1.4.0

本次更新重新设计了额度卡片的信息结构，让 Codex、Cursor 和 Claude Code 在返回不同数量的额度数据时，都能保持清晰、一致的阅读体验。

## 新增

- 自适应额度布局：单项额度使用全宽进度条，双项额度并排对比，三项及以上额度使用紧凑圆环。
- 多产品、多会员类型的界面回归截图，覆盖 Free、Plus、Pro、Team、Ultra 与 Claude.ai 等状态。

## 改进

- 重新梳理账号、会员状态、额度数值、重置时间与更新时间的文字层级。
- 优化字号、字重和内容间距，同时保持面板与账号卡片高度不变。
- 精简单账号场景的页头，并将设置入口统一收纳到顶部操作区。
- 使用真实接口返回的额度数量构建卡片，不再为缺失指标保留无效占位。

## 修复

- 修复刷新失败时错误信息与“刷新中”状态同时出现的问题。
- 修复缓存错误在切换界面语言后未重新本地化的问题。
- 修复部分错误信息过长、影响卡片主要内容阅读的问题。

## 安装

下载适合设备的 DMG：arm64（Apple Silicon）、x86_64（Intel）或 universal（通用）。将 QuotaBar.app 拖入 Applications，校验文件随安装包提供。

当前安装包使用 ad-hoc 签名、未经 Apple 公证。安装与首次打开说明见 README。
